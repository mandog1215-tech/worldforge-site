# WorldForge public site

The project's public hub. It is a *view* of the development record,
never a second source of truth.

## Standing rules (adopted 2026-10-31)

1. **Status changes require evidence.** A feature does not become
   "working" or "established" because a page changed colour — only
   when the development record (milestone registry, gate reports,
   evidence archive) supports the transition.
2. **Known gaps remain visible until genuinely resolved.** The gaps
   register on `evidence.html` shrinks only when a gap is closed with
   evidence — never because a page was redesigned or a nearby system
   improved. In particular, the ecology question stays listed until
   it is answered, not merely better explained.
3. **The roadmap follows the gates, not the calendar.** Phases begin
   when the previous gate passes, however polished the site looks.
   Statuses are updated at milestone/gate closeouts, in the same pass
   as the work's report.

If anything here conflicts with the development record, the record
is right and the site gets corrected.
